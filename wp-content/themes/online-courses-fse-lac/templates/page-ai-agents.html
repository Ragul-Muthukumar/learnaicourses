An AI agent does more than answer a chat. It plans the next step, uses a tool, checks the result, and keeps going until the job is done — or until it should stop. This path covers that loop: chatbots, document retrieval, planning, guardrails, and coordinating more than one agent.

Start here if you already write prompts and want systems that finish work. You do not need to be a software engineer. The early courses stay practical; later ones go deeper into reliability and multi-step runs.

What you will learn

Plan and act

Break a request into steps, choose a tool, and run the next action instead of stopping at a single reply.

Use your own data

Connect files and search so the agent answers from your documents instead of guessing from general knowledge.

Keep runs reliable

Add checks, limits, and recovery so an agent can fail a step without derailing the whole task.

How the path is sequenced

Take these in order if agent systems are new. Skip the first course if you already run a chatbot or custom GPT.

  1. Ship a simple chatbot — instructions, answers, and a clear job for the assistant.
  2. Point it at your files — retrieval so replies come from your process, not generic advice.
  3. Add planning and tools — multi-step agents that act, then check what happened.
  4. Harden the run — guardrails, recovery, and more than one agent on a larger job.

What a reliable agent needs

A single clever prompt is not an agent. Across this path you will practice putting these parts in place:

  • Goal — the outcome the run should reach, in language a person would accept as “done.”
  • Tools — search, documents, APIs, or forms the agent is allowed to call.
  • Memory — what to keep from earlier steps so the next action is not starting from zero.
  • Checks — how to tell a good result from a guess, a loop, or an unsafe action.
  • Stop conditions — when to ask a person, retry, or end the run.

Who this path is for

This sequence is a fit if you already use chat tools and now need work to move without you copying every step by hand. It also suits product and operations people who want agents that stay inside a defined job.

If you are still learning how to write a clear prompt, start with the Prompt Engineering path. If your next step is connecting models to everyday process flows and APIs, continue to AI Automation.

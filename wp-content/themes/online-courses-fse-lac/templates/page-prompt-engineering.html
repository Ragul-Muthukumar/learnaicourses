Prompt engineering is the skill of giving an AI model clear instructions so the output is useful on the first try — and easy to improve on the second. This path takes you from a first prompt to repeatable patterns you can use for writing, research, images, and evaluation.

You do not need a technical background. Each course is short, self-paced, and built around work you already do: emails, documents, ideas, and visual drafts.

What you will learn

Prompt structure

Write prompts with a role, a task, the context the model needs, and a clear format for the answer.

Refinement loops

Turn a weak draft into a stronger one by adding constraints, examples, and one change at a time.

Evaluating output

Check accuracy, tone, and completeness before you paste a model answer into real work.

How the path is sequenced

Take the courses in this order if you are starting from scratch. Skip ahead if you already use ChatGPT or similar tools every day.

  1. Write a first prompt — see how instructions, context, and format change the answer.
  2. Use prompts on daily work — emails, lists, summaries, and research notes.
  3. Learn repeatable patterns — roles, examples, constraints, and evaluation checklists.
  4. Go further — image prompts, output quality checks, and when prompting is enough versus fine-tuning.

What a strong prompt includes

Most weak results come from vague instructions. Across this path you will practice putting these parts in writing:

  • Role — who the model should act as, such as an editor, analyst, or teacher.
  • Task — the exact job: rewrite, summarize, compare, generate options, or critique.
  • Context — the audience, product, constraints, and source material the model cannot guess.
  • Examples — one or two samples of the tone or format you want.
  • Output format — bullets, a table, a subject line plus body, or a fixed word count.
  • Checks — what “good” looks like, and what the model should flag as uncertain.

Who this path is for

This sequence is a fit if you already work with documents, products, or software and need a clearer way to use AI tools on the job. It is also a practical start if you have tried a chatbot once or twice and want a method instead of trial and error.

It is not a coding bootcamp. If your next step is tool-using agents or API workflows, continue to the AI Agents or AI Automation paths after these courses.
